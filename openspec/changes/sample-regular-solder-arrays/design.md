## Context

参见 `proposal.md` 的动机。首轮联系表证明，仅按圆形重复结构会混入连接器、不同芯片封装和整板阵列。用户已指定 `DataV1/数据集/X光图片20260804/未标注/焊点桥连/焊点桥连 (2).jpg` 中的正视芯片为目标元件族，因此筛选必须同时建模元件级外观和内部网格，而不是把所有黑色圆点视为同类。

## Goals / Non-Goals

**Goals:**

- 在新目录 `solder_joint_mvp/` 中形成可独立运行、可逐步验证的命令行流水线。
- 先用缩略图筛选与锚点同族的正视芯片，再在芯片内部用可解释几何特征定位圆点网格。
- 对全部图片自动生成视觉摘要和近重复组，只让模型与用户审核有限候选。
- 将人工工作压缩到阵列级确认和少量关键点纠错，不要求逐焊点分割。
- 所有中间结果通过样本 ID、配置快照和算法版本保持可追溯。

**Non-Goals:**

- 首轮不训练通用语义/实例分割模型，不使用扩散模型生成数据。
- 不自动判定具体焊点缺陷类别；生成的 ROI 只为下一阶段分类或异常检测准备输入。
- 不把其他规则圆形阵列元件、连接器或不同芯片封装作为首轮正例。
- 不承诺支持强透视侧视、焊点彼此严重粘连、任意非规则封装或整板上所有器件。

## Decisions

### 1. 独立工作区且只引用原始数据

新代码放入 `solder_joint_mvp/`，其 `manifests/` 保存路径和元数据，`outputs/` 保存可再生结果。原始 JPG/ZIP 不复制到新目录。相较于重新整理一份数据副本，这能避免磁盘重复、路径失配和 Git 误提交。

建议结构：

```text
solder_joint_mvp/
  README.md
  pyproject.toml
  configs/mvp.yaml
  src/solder_mvp/
    inventory.py
    sampler.py
    candidate_detector.py
    grid_fitter.py
    roi_exporter.py
    evaluator.py
    cli.py
  manifests/
  reviews/
  outputs/
  tests/
```

### 2. 锚点与目标族采用显式配置

配置保存锚点路径、目标族名称和可观察定义。首轮目标族暂命名为 `frontal-chip-internal-dot-grid-v1`：芯片接近正视、矩形封装外框清楚、近圆形焊点位于封装内部并形成二维网格。使用可版本化定义而不是仅依赖目录缺陷名称，因为相同元件可能分散在桥连、空洞、多余物等目录中。

### 3. 三阶段筛选代替逐张模型审核

第一阶段对全部可读取图片生成低分辨率灰度、中心区域、边缘和感知哈希摘要，并按视觉距离形成近重复组。第二阶段以锚点的多种摘要计算全局同族相似度，优先保留封装长宽比、中心矩形结构和内部二维周期与锚点接近的图片；来源配额只用于高分结果中的多样性控制，不再轮询所有来源。第三阶段把高分候选制成每批 40 张的联系表，由 Codex 初审并输出四类建议，再由用户确认少量边界样本。

备选方案是将 4,695 张原图逐张提交给视觉模型；该方案耗额度、复核口径易漂移且无法自然处理重复图，因此不采用。

### 4. 用几何网格替代逐点分割

候选圆心先按尺度与局部对比度过滤，再通过鲁棒模型估计两个近似正交的阵列基向量，聚类得到行列索引，并以残差、缺失比例、半径离散度和间距离散度形成置信度。备选方案是直接使用实例分割；但首轮缺少大量像素标签，且规则阵列本身提供了更强的先验。

### 5. 复核标签同时表达元件族与可用性

每个候选生成带编号、同族分数、重复组和来源的预览图。复核标签为：`keep`（同族且视角可用）、`other_component`（规则圆阵列但不同元件）、`reject`（视角或结构不适用）、`uncertain`（需用户判断）。必要时只补充芯片框、四角、行列数或少量正确圆心。首版兼容普通 JSON/CSV 编辑，也预留导出 LabelMe 点/矩形标注的能力。

### 6. 按近重复组固定验证集

复核完成后以近重复组为不可拆分单位划分开发集和验证集，防止同一视野或其标注版本跨集合泄漏。阈值只在开发组调整，最终报告同时给出目标族检索、其他元件混入率和焊点级指标。

### 7. 最小人工与自动化责任边界

可由代码和 Codex 自动完成：目录盘点、视觉摘要、近重复分组、同族候选排序、分批初审、预览生成、网格拟合、ROI 裁切、格式导出、指标统计和失败案例汇总。

必须由用户完成：确认 Codex 初审中的少量边界样本；为评估集修正少量芯片范围、行列数或中心点；定义哪些缺陷外观应纳入下一阶段。目标锚点已经确认，用户无需逐个焊点画分割轮廓。

## Risks / Trade-offs

- [亮暗极性、曝光和放大倍率差异导致圆检测不稳定] → 使用局部对比度归一化、多尺度候选及按来源分层评估。
- [规则背景结构被误认为焊点阵列] → 同时约束二维周期性、圆尺度一致性和候选区域密度，并保留人工阵列级确认。
- [不同元件拥有相似圆形网格] → 在网格特征之外加入封装外框、视角和中心区域相似度，并用 `other_component` 单独记录。
- [同一拍摄对象的近重复图造成指标虚高] → 在抽样和数据划分前建立近重复组，组内样本不得跨集合。
- [缺陷焊点偏离圆形后被当作缺失] → 网格先由多数正常焊点确定，再为低响应位置保留预期中心，供后续异常检测使用。
- [路径移动后清单失效] → 同时记录配置中的数据根别名、相对路径、文件大小和可选内容摘要，并提供重新定位检查。
- [首轮规则场景指标不能代表全部数据] → 报告显式记录适用范围，后续侧视/遮挡场景作为独立能力扩展，而不是混入同一阈值。

## Migration Plan

这是新增且隔离的实验目录，无现有数据迁移。删除 `solder_joint_mvp/` 及本变更产生的可再生输出即可回滚，不影响旧流程和原始数据。
