## Context

参见 `proposal.md` 的动机。项目中图片和 JSON 数量较大，数据分散在既有目录中，部分图片已有缺陷类别或椭圆/框标注，但缺少统一的规则阵列与焊点中心定义。首轮实验需要控制人工成本，并保持与现有代码和原始数据解耦。

## Goals / Non-Goals

**Goals:**

- 在新目录 `solder_joint_mvp/` 中形成可独立运行、可逐步验证的命令行流水线。
- 先用缩略图和可解释几何特征筛选规则圆形阵列，再在候选区域用原始分辨率精定位。
- 将人工工作压缩到阵列级确认和少量关键点纠错，不要求逐焊点分割。
- 所有中间结果通过样本 ID、配置快照和算法版本保持可追溯。

**Non-Goals:**

- 首轮不训练通用语义/实例分割模型，不使用扩散模型生成数据。
- 不自动判定具体焊点缺陷类别；生成的 ROI 只为下一阶段分类或异常检测准备输入。
- 不承诺支持强透视侧视、焊点彼此严重粘连、任意非规则封装或整板上所有器件。

## Decisions

### 1. 独立工作区且只引用原始数据

新代码放入 `solder_joint_mvp/`，其 `manifests/` 保存路径和元数据，`outputs/` 保存可再生结果。原始 JPG/ZIP 不复制到新目录。相较于重新整理一份数据副本，这能避免磁盘重复、路径失配和 Git 误提交。

建议结构：

```text
solder_joint_mvp/
  README.md
  pyproject.toml
  configs/mvp.yaml
  src/solder_mvp/
    inventory.py
    sampler.py
    candidate_detector.py
    grid_fitter.py
    roi_exporter.py
    evaluator.py
    cli.py
  manifests/
  reviews/
  outputs/
  tests/
```

### 2. 两阶段图像处理

第一阶段将图片等比例缩小，在灰度归一化后提取近圆形重复结构，计算候选得分，以便快速扫过大量图片。第二阶段只对入选区域读取原分辨率图像并精定位。相较于对全部图片跑重模型，这种方式更适合当前“先抽样验证”的目标，也更容易解释失败原因。

### 3. 用几何网格替代逐点分割

候选圆心先按尺度与局部对比度过滤，再通过鲁棒模型估计两个近似正交的阵列基向量，聚类得到行列索引，并以残差、缺失比例、半径离散度和间距离散度形成置信度。备选方案是直接使用实例分割；但首轮缺少大量像素标签，且规则阵列本身提供了更强的先验。

### 4. 人工复核采用轻量 JSON 清单和叠加图

每个候选生成带编号圆心、网格线和候选框的预览图。人工只需在复核清单中填写 `keep/reject/uncertain`；必要时补充阵列框、四角、行列数或少量正确圆心。首版优先兼容普通 JSON/CSV 编辑，也预留导出 LabelMe 点/矩形标注的能力，避免绑定单一 GUI。

### 5. 先固定验证集，再调阈值

从不同数据来源中按固定种子抽取一小批候选与负例，人工一次性确认后作为冻结验证集。阈值只在其余开发样本上调整，最终报告同时给出阵列级和焊点级指标，防止只展示“看起来不错”的样例。

### 6. 最小人工与自动化责任边界

可由代码自动完成：目录盘点、可复现抽样、候选评分、预览生成、网格拟合、ROI 裁切、格式导出、指标统计和失败案例汇总。

必须由用户完成：确认首轮目标外观是否确为所需封装；复核一小批候选的保留/排除；为评估集修正少量阵列范围、行列数或中心点；定义哪些图像质量和缺陷外观应被纳入下一阶段。用户无需逐个焊点画分割轮廓。

## Risks / Trade-offs

- [亮暗极性、曝光和放大倍率差异导致圆检测不稳定] → 使用局部对比度归一化、多尺度候选及按来源分层评估。
- [规则背景结构被误认为焊点阵列] → 同时约束二维周期性、圆尺度一致性和候选区域密度，并保留人工阵列级确认。
- [缺陷焊点偏离圆形后被当作缺失] → 网格先由多数正常焊点确定，再为低响应位置保留预期中心，供后续异常检测使用。
- [路径移动后清单失效] → 同时记录配置中的数据根别名、相对路径、文件大小和可选内容摘要，并提供重新定位检查。
- [首轮规则场景指标不能代表全部数据] → 报告显式记录适用范围，后续侧视/遮挡场景作为独立能力扩展，而不是混入同一阈值。

## Migration Plan

这是新增且隔离的实验目录，无现有数据迁移。删除 `solder_joint_mvp/` 及本变更产生的可再生输出即可回滚，不影响旧流程和原始数据。

## Open Questions

- 首批人工复核的候选数量默认设为 40 张，可在实际预览生成后根据同质重复程度下调。
- 首轮 ROI 是否保留原始灰度位深将在读取样本元数据后决定；无论选择何种位深，清单都会记录转换过程。
