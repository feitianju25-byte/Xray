## Why

现有 X 光图像中单图焊点数量多，逐点手工分割成本过高；同时不同视角下焊点外观差异明显，直接从全量数据训练通用分割模型风险较大。首个最小可行实验应先聚焦多行、规则、近圆形焊点阵列，验证能否用几何规律自动完成样本筛选、焊点中心定位和 ROI 生成。

## What Changes

- 新建独立目录 `solder_joint_mvp/`，与现有训练、标注和桌面程序隔离。
- 扫描现有数据集并生成轻量清单，只记录图片路径、尺寸、来源和筛选状态，不复制或提交 JPG/ZIP。
- 支持人工少量指定正例后，对多行规则圆形焊点阵列进行候选筛选和可视化复核。
- 对候选阵列拟合行列网格，输出每个焊点的中心、半径/尺度、行列编号和置信度。
- 根据网格自动裁切统一尺度的焊点 ROI，并导出可复现的清单与预览图，为后续缺陷分类或少量人工修正提供输入。
- 提供定量评估，重点衡量阵列级筛选准确性、焊点中心召回率和 ROI 可用率。
- 本次不覆盖侧视严重形变、密集遮挡、非规则散布焊点和整板任意器件定位，也不训练扩散模型。

## Capabilities

### New Capabilities

- `regular-solder-array-sampling`: 从现有 X 光数据中筛选规则圆形焊点阵列、拟合网格并生成可追溯焊点 ROI 样本的能力。

### Modified Capabilities

无。

## Impact

- 新增代码和配置位于 `solder_joint_mvp/`，不会直接修改现有 `screen_recognition_app/`、`pcb_xray_annotation_workspace/` 或 `DataV1/` 流程。
- 输入以现有图片的绝对或项目相对路径引用；原始 JPG 和 ZIP 不复制、不纳入 Git。
- 计划使用 Python、OpenCV、NumPy 和 Pillow；首轮优先采用可解释的图像处理与鲁棒几何拟合，暂不引入大型生成模型依赖。
- 输出包括 JSON/CSV 清单、焊点 ROI、叠加预览和评估报告；其中生成物目录默认由 Git 忽略，仅保留配置、代码和小型报告模板。
