## Why

现有 X 光图像中单图焊点数量多，逐点手工分割成本过高；而且不同元件即使都呈黑色圆形阵列，其封装外框、间距、层叠投影和缺陷标准也不同，混合训练会掩盖实验结论。首个最小可行实验应聚焦 `DataV1/数据集/X光图片20260804/未标注/焊点桥连/焊点桥连 (2).jpg` 所代表的芯片正视图元件族，先验证同族检索、内部网格定位和 ROI 生成。

## What Changes

- 新建独立目录 `solder_joint_mvp/`，与现有训练、标注和桌面程序隔离。
- 扫描现有数据集并生成轻量清单，只记录图片路径、尺寸、来源和筛选状态，不复制或提交 JPG/ZIP。
- 以 `焊点桥连 (2).jpg` 为锚点定义第一目标元件族：芯片接近正视、矩形封装外框清楚、圆形焊点位于封装内部并形成二维网格。
- 自动遍历现有图片的缩略图特征，先做近重复分组，再按元件外观、视角和内部圆点网格相似度排序，避免把所有图片逐张提交给模型审核。
- 将规则圆形但属于其他元件的图片标为 `other_component`，不与目标族 `keep` 混合。
- 对候选阵列拟合行列网格，输出每个焊点的中心、半径/尺度、行列编号和置信度。
- 根据网格自动裁切统一尺度的焊点 ROI，并导出可复现的清单与预览图，为后续缺陷分类或少量人工修正提供输入。
- 提供定量评估，重点衡量阵列级筛选准确性、焊点中心召回率和 ROI 可用率。
- 本次不覆盖其他圆形阵列元件族、侧视严重形变、密集遮挡、非规则散布焊点和整板任意器件定位，也不训练扩散模型。

## Capabilities

### New Capabilities

- `regular-solder-array-sampling`: 从现有 X 光数据中筛选与锚点相同的正视芯片元件族、拟合其内部圆点网格并生成可追溯 ROI 样本的能力。

### Modified Capabilities

无。

## Impact

- 新增代码和配置位于 `solder_joint_mvp/`，不会直接修改现有 `screen_recognition_app/`、`pcb_xray_annotation_workspace/` 或 `DataV1/` 流程。
- 输入以现有图片的绝对或项目相对路径引用；原始 JPG 和 ZIP 不复制、不纳入 Git。
- 计划使用 Python、OpenCV、NumPy 和 Pillow；首轮优先采用可解释的图像处理与鲁棒几何拟合，暂不引入大型生成模型依赖。
- 输出包括 JSON/CSV 清单、近重复组、同族相似度、四类复核结果、焊点 ROI、叠加预览和评估报告；其中生成物目录默认由 Git 忽略，仅保留配置、代码和小型报告模板。
