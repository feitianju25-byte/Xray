# 焊点规则阵列路线搁置记录

状态：已搁置  
日期：2026-09-16

## 原始目标

以 `DataV1/数据集/X光图片20260804/未标注/焊点桥连/焊点桥连 (2).jpg` 中的芯片正视图为目标元件族，先筛选同族芯片，再利用内部规则圆形阵列拟合行列网格，自动裁切可追溯的焊点 ROI。该路线试图用几何先验减少逐焊点像素分割标注。

## 已完成的验证

- 只读扫描 2,160 张未标注图，建立 1,881 个近重复组；
- 生成 120 张候选联系表，人工确认 17 张同族正例；
- 按重复组冻结为 7 张开发集和 10 张验证集，跨集合泄漏为 0；
- 实现明暗圆候选、区域评分、双基向量网格拟合、缺失点推断、ROI 导出和 LabelMe 导出；
- 实现用于框选芯片并填写阵列行列数的本机可视化标注器；
- 删除前自动测试为 40 项通过，原始 JPG/JPEG/ZIP 始终未纳入 Git。

## 暂停原因

- 不同元件可能呈现相似的黑色圆形结构，仅凭圆阵列难以判断元件语义；
- 在真实锚点图上，规则检测器可能选择稀疏亮环，而不是目标芯片内部的密集暗点网格；
- 不同视角、遮挡和层叠投影使单一规则算法的适用范围较窄；
- 路线尚未完成 10 张验证图的人工几何复核，也未生成最终冻结验证报告；
- 当前决定暂停焊点切割，转向其他路线尝试。

## 如果以后恢复

删除前的最新完整实现位于 Git 提交 `17c0e8b`。可从该提交恢复原目录：

```powershell
git restore --source=17c0e8b -- solder_joint_mvp
```

恢复后建议优先尝试“元件检测/检索 → 芯片局部裁切 → 局部焊点分析”的分阶段方案，而不是直接在整板图上做通用焊点分割。若需要覆盖侧视或遮挡，应作为独立数据族与独立评估集处理。
