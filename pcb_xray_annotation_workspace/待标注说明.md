# 三类缺陷待标注工作区

## 目录

- `images/void`：焊点空洞
- `images/bridge`：焊点桥连
- `images/insufficient_through_solder`：透锡不足
- `references/red_marked/void`：焊点空洞红圈参考图
- `references/red_marked/bridge`：焊点桥连红圈参考图
- `references/red_marked/insufficient_through_solder`：透锡不足红圈参考图
- `manifests/dataset_manifest.csv`：每张整理后图片的来源和唯一哈希
- `manifests/red_reference_manifest.csv`：待标注图和红圈参考图的对应关系
- `manifests/duplicates_exact.csv`：精确重复但未复制的图片
- `manifests/label_conflicts.csv`：同一哈希被归入不同类别的冲突记录
- `manifests/summary.json`：整理统计

## 标注方式

请直接用 X-AnyLabeling 打开 `images` 目录下的三类文件夹，在原始图上标注。

第一版只使用三个标签：

- `void`
- `bridge`
- `insufficient_through_solder`

建议框选范围：

- `void`：框住出现空洞的完整焊点；
- `bridge`：框住相连的两个焊点及中间连接区域；
- `insufficient_through_solder`：框住完整插针、焊盘和透锡柱区域。

带红圈的参考图没有复制到本工作区。正常图片不需要画 `normal` 框。

请尽量保留图片文件名。标注生成的 JSON 可与图片放在同一目录，后续会据此转换训练格式。
